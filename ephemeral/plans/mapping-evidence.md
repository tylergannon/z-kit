## Current proposal revision

The user's later review superseded the draft's dedicated absent/present wrapper and primary external metadata-table recommendation. The preferred proposal is ordinary `?T`, omittable by default, with an inline public namespace const carrying a per-field required override that emits null for native null, using the same policy for codecs, TS, JSDoc and later schema. Absent key and own undefined remain distinct; explicit undefined and three-state absent/null/value acceptance are refused initially. The user chose these default/override semantics; carrier spelling, other mapping policies and implementation remain open. This revision implements no API.
